# Cognivanta Demo Walkthrough

This script is designed for a polished 90–120 second GitHub demo video. Keep the edit fast, use clean screen recordings, and show the product loop rather than every feature.

## Demo title

**Cognivanta — From Handwritten Notes to an Interactive Learning Universe**

## Recommended recording setup

- Resolution: 1920×1080 or 1440×900
- Frame rate: 30 or 60 fps
- Browser zoom: 90–100%
- Hide browser bookmarks and personal notifications
- Use a clean demo account with one prepared note image
- Keep the AI service running or use the documented mock mode
- Record narration separately for cleaner audio
- Export as MP4/H.264; keep the README preview under roughly 20–30 MB

## Storyboard and narration

| Time | Screen direction | Voice-over |
| --- | --- | --- |
| 0:00–0:08 | Open the Cognivanta dashboard. Let the brand, Daily Mission, and Focus Sprint appear. | “Studying is usually split between notes, revision, quizzes, and scattered tools. Cognivanta brings that entire learning loop into one intelligent workspace.” |
| 0:08–0:20 | Move to the note upload area. Drag in a prepared handwritten page or diagram. Show the page preview and multi-page upload controls. | “Start with the material you already have. Upload handwritten notes, diagrams, or multiple study pages, and Cognivanta turns them into structured learning data.” |
| 0:20–0:34 | Select the Concept Matrix or graph generation mode. Click analyse and show the processing state. | “Its multimodal pipeline transcribes the source, identifies important ideas, and validates the relationships between them before displaying the result.” |
| 0:34–0:50 | Reveal the generated concept graph. Click a primary node, then a connected node. | “The Concept Matrix makes the structure visible. Select a node to read its explanation, follow related concepts, and understand how the ideas connect.” |
| 0:50–1:05 | Open a linked active-recall question. Select an answer and show the explanation/XP feedback. | “Learning does not stop at reading. Every concept can become an active-recall challenge, with instant feedback and a clear reason behind the answer.” |
| 1:05–1:20 | Switch to Biology, Physics, History, or Geography from Core Spaces. Briefly show one world/realm and its navigation. | “When you want a different way to learn, enter one of the interactive subject worlds. Cognivanta turns abstract material into explorable spaces without hiding the underlying explanation.” |
| 1:20–1:34 | Return to the top panel. Start the Focus Sprint and show the timer running. | “The built-in Focus Sprint turns intention into a study session. Daily missions adapt to the space you are using, while completed focus sessions contribute to your progression.” |
| 1:34–1:48 | Open Profile. Scroll across stats, activity heatmap, streak, and saved notes. | “Your profile keeps the journey visible: saved notes, generated learning spaces, quiz history, activity streaks, and XP.” |
| 1:48–2:00 | End on the Cognivanta brand/dashboard. Show the GitHub URL in a small end card. | “Cognivanta is built for one simple outcome: move from scattered information to connected understanding. Explore the repository and build your own learning universe.” |
