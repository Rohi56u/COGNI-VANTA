# Contributing to Cognivanta

Thanks for helping improve Cognivanta. Keep contributions focused, explain the user value, and preserve the learning loop: capture, understand, connect, recall, and master.

## Before opening a pull request

1. Create a focused branch from `main`.
2. Do not commit `.env` files, credentials, databases, uploads, `node_modules`, or build output.
3. Run the relevant frontend build and backend/AI syntax checks locally.
4. Update documentation when a user-facing workflow or environment variable changes.
5. Include screenshots or a short reproduction for visual or interaction changes.

## Pull request guidance

Describe the problem, the solution, test coverage, and any follow-up work. Smaller pull requests are easier to review and safer to merge.
